# Linux Server Monitoring Tool

A Bash-based Linux server monitoring tool that checks important server health metrics such as CPU usage, memory usage, disk usage, running processes, and server uptime.

## Features

- CPU usage monitoring
- Memory usage monitoring
- Disk usage monitoring
- Running process count
- Server uptime
- Overall server health status
- Warning when CPU, memory, or disk usage exceeds 80%

- Linux
- Ubuntu
- Bash
- Git
